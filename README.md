# AI-Based Farmer Income Prediction and Agricultural Socio-Economic Analysis

## Overview

Farmer income is influenced by a wide range of factors, including agricultural productivity, land availability, climatic conditions, irrigation facilities, financial status, infrastructure, and the socio-economic characteristics of the region.

This project presents a **Machine Learning and Deep Learning based Farmer Income Prediction System** designed to predict the total income of farmers using agricultural, climatic, financial, demographic, and socio-economic indicators.

The project performs data preprocessing, exploratory data analysis, feature engineering, model training, prediction, performance evaluation, and visualization. In addition to the base predictive model, optimization approaches based on **Artificial Immune System (AIS)** and **Particle Swarm Optimization (PSO)** are used for feature selection and model improvement.

The primary prediction target is:

`Target_Variable/Total Income`

---

## Project Objective

The main objective of this project is to develop an intelligent predictive system capable of estimating farmer income from multiple agricultural and socio-economic indicators.

The project aims to:

- Analyze agricultural and socio-economic factors associated with farmer income.
- Preprocess large structured datasets containing numerical and categorical variables.
- Handle missing values and inconsistent data.
- Predict the total income of farmers using machine learning and neural networks.
- Evaluate prediction performance using regression metrics.
- Identify important features affecting farmer income.
- Apply Artificial Immune System (AIS) based feature selection.
- Apply Particle Swarm Optimization (PSO) based feature selection.
- Generate predictions for unseen farmer records.
- Produce graphical and CSV-based outputs for further analysis.
